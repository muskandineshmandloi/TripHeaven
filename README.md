# TripHeaven 🏨

A full-stack travel and hotel listing platform where users can 
explore, list, and review hotels.

## Live Demo
[TripHeaven Live](https://tripheaven-1g1o.onrender.com/)

## Tech Stack
- Node.js, Express.js
- MongoDB, Mongoose
- EJS Templates
- Passport.js (Authentication)
- Cloudinary (Image uploads)
- Deployed on Render

## Features
- User registration and login
- Create, edit, delete hotel listings
- Add and delete reviews
- Image upload via Cloudinary
- Input validation and sanitization
- Protected routes with authorization

## Setup
1. Clone the repo — `git clone https://github.com/muskandineshmandloi/TripHeaven`
2. Run `npm install`
3. Add `.env` with your MongoDB, Cloudinary, and session secret
4. Run `node app.js`
